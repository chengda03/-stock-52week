# 연간 영업이익 데이터

`annual_operating_profit.csv` 파일을 이 폴더에 넣으세요. 필수 컬럼: `code,period_end,disclosed_at,operating_profit`.

- code: 6자리 종목코드 (예: 005930)
- period_end: 회계연도 종료일 (예: 2024-12-31)
- disclosed_at: 실제 사업보고서 공시일 (예: 2025-03-14)
- operating_profit: 연간 영업이익, 원 단위. 연결기준 우선
- 정정공시는 실제 정정 공시일의 별도 행으로 기록
- 적어도 2018~2026년 공시 이력이 있어야 2020~2026 검증의 초기 구간에서 누락을 줄일 수 있습니다.
- 공시 이전 데이터를 소급 사용하지 않습니다. 정보가 없으면 매수 제외합니다.

공시 이력은 금융감독원 DART 등에서 취득해야 하며, 이 저장소에는 아직 해당 데이터가 없습니다.
